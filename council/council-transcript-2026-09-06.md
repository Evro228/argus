# ARGUS Engineering Council // Заседание Совета 06.09.2026

## 1. Поставленный вопрос
Внедрение комплексной защиты десктопного комплекса ARGUS (Localhost IPC Token против drive-by запросов, строгая изоляция Air-Gapped Stealth Mode, шифрование локальных данных AES-256-GCM, зачистка секретов в RAM) и проведение тяжелых нагрузочных тестов.

## 2. Позиции советников

### The Contrarian
- Обратил внимание на иллюзорность зачистки RAM при использовании обычных строк из-за интернирования и сборщика мусора.
- Предупредил о риске коллапса Event Loop при синхронном AES-256-GCM на сотнях одновременных запросов.
- Настоял на выносе криптографии, использовании `ctypes.memset` для физического затирания и константного сравнения токенов `secrets.compare_digest`.

### The First Principles Thinker
- Сформулировал модель доверия: передача токена в Python строго через приватное окружение процесса (не через CLI аргументы `ps aux`).
- Валидация Host-заголовка для защиты от DNS Rebinding.
- Запрет сброса страниц памяти с ключами в core-дамп через `setrlimit(RLIMIT_CORE, 0)`.

### The Expansionist
- Разделение Control Plane и Data Plane.
- Использование блочного/потокового AES-256-GCM с контролем целостности (AEAD) и AAD.
- Нагрузочные тесты на отказ с одновременным штормом асинхронных сессий.

### The Outsider
- Бесшовная интеграция для оператора без ручного ввода паролей IPC.
- Четкая индикация Air-Gap в статус-баре.
- Восстановление сессии без потери данных при аварийном завершении.

### The Executor
- Разработал и внедрил `backend/app/utils/memory.py` с классом `SecureBuffer`.
- Разработал `backend/app/utils/crypto_vault.py` (AES-256-GCM).
- Создал тяжелый стресс-тест `tests/stress_test.py` (500 одновременных запросов, фаззинг Host, зануление RAM).
- Расширил регрессионный пакет `tests/test_suite.py` до 30 проверок.

## 3. Вердикт и итоги

- Все 6 из 6 тяжелых нагрузочных стресс-тестов пройдены успешно (100.0%, 2230+ RPS, 0 сбоев).
